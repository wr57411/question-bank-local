# Agents 索引文件模板

## 用途

在项目根目录维护 `agents.md`（或 `AGENTS.md`），作为全仓开发文档的索引目录。AI执行任何操作前必须先查询此索引，锁定相关历史文档路径，避免全量扫描导致Token爆炸。

## 索引文件格式

```markdown
# Agents 索引

> 本文件是项目开发文档的索引目录。AI执行任何操作前必须先查询此文件。
> 新增文档后必须在此追加条目。
```

## 初始化指引

在项目根目录执行以下步骤创建索引：

1. 创建 `agents.md` 文件，复制上方模板结构
2. 扫描项目中已有的 `docs/` 目录（或约定文档目录）
3. 为每个已有文档添加索引条目
4. 后续每次开发操作完成后，追加新条目

## 索引维护规则

- **新增文档时：** 在对应分类表格末尾追加一行
- **文档废弃时：** 在条目后标注 `[已废弃]`，不直接删除（保留回溯能力）
- **文档更新时：** 更新功能说明列，保持描述与实际内容一致
- **分类新增时：** 在末尾追加新的分类表格
