📋 一、产品概述

1.1 背景与动机

当前项目的 src/data/pdf.ts 模块负责将题目图片导出为 PDF 文档。核心逻辑是：获取图片原始尺寸 → 按页面宽度等比缩放 → 调用 jsPDF.addImage() 写入。

⚠️ 核心问题：不同拍摄距离/缩放级别的题目照片在导出后文字大小差异巨大。近距离拍摄的照片文字很大，远距离拍摄/截图放小的照片文字很小。当前代码只做等比缩放（所有图铺满 A4 宽度），完全没有考虑图片内部文字的"有效分辨率"。

1.2 目标用户与场景

  • 主要用户：使用 question-bank-local 应用的教师/学生，需要批量导出题目图片为可打印的 PDF 文档
  • 使用场景：手机拍照或截图录入题目 → 批量选择导出 → 打印/分享 PDF
  • 痛点：导出的 PDF 中不同题目的文字大小不一致，影响阅读体验和打印效果

🔧 三、技术方案

3.1 核心算法流程

上传图片
→
检测文字高
→
计算缩放系数
→
基准线归一化
→
A4 排版渲染
→
导出 PDF

步骤详解

  1. 文字高度检测（O(n) 快速算法）
    • 降采样至最长边 ≤ 800px
    • 全局均值亮度阈值二值化（threshold = mean × 0.88）
    • 行采样水平投影（每 ~200 列采一个点，4× 加速）
    • 检测文字行段 → 取中位数作为该图文字行高
    • 性能：<80ms/张（1400×1050 图片）
  2. 缩放系数计算 
    // 对每张图片 i：
usableWidth_i = layoutMode == 'single' ? 190mm : 77mm
textHeightAtFull = (detectedPx / imgWidth) * usableWidth_i
rawScale_i     = targetTextMM / textHeightAtFull

// 归一化：以中位数为基准
baselineScale  = median(rawScale_1, ..., rawScale_n)
normScale_i    = clamp(0.35, 1.0, rawScale_i / baselineScale)
  3. 布局引擎（纯迭代，队列驱动）
    • 维护「当前页面状态」：左栏剩余高度 / 右栏剩余高度
    • 对队列中每个图片项：尝试放入当前栏 → 放不下则切割 → 剩余部分重新入队
    • 最大迭代次数保护（300 次）防止死循环

🎨 四、交互设计

4.1 界面布局：左右分栏

  • 左侧面板（340px）：控制区 + 图片列表 + 日志
    • 上传区域（拖拽/点击）
    • 控制栏：检测方式、目标文字大小、批量布局按钮
    • 操作按钮：分析+排版、测试图、导出 PDF、清空
    • 统计信息：图片数、单/双栏分布、页数、切割次数
    • 图片列表：每项含缩略图、名称、尺寸、文字高度、布局切换、删除
    • 日志区域：实时输出处理过程
  • 右侧面板（弹性）：A4 实时预览
    • 页码导航（◀ 第 N / M 页 ▶）
    • A4 画布（595pt × 842pt 白色区域）
    • 列参考线 + 切割标记（金色横线 + ✂ 标签）

4.2 用户操作流程

典型流程（首次使用）：
  1. 打开 pdf-text-normalize-prototype.html
  2. 点击「🧪 测试图」加载 4 张模拟图片（或自行上传真实题目照片）
  3. 根据需要切换各图片的单栏/双栏布局（默认全部单栏）
  4. 点击「🔍 分析+排版」→ 等待 <2 秒
  5. 右侧 A4 画布实时呈现排版结果，可翻页浏览
  6. 观察统计数据：文字高度范围、最大偏差、归一化后范围、切割次数
  7. 满意后点击「📄 导出 PDF」下载文件

4.3 视觉规范

  • 配色：深色主题（#0f1117 背景），减少长时间使用的视觉疲劳
  • 状态色：成功 #34d399 / 警告 #fbbf24 / 错误 #f87171 / 主色 #6c8cff
  • A4 预览：白色画布 + 微阴影，模拟真实纸张效果

📊 五、数据模型

5.1 内部状态结构

{
  imgs: [{
    id: string,           // 唯一标识
    f: File,               // 原始 File 对象
    url: string,           // Data URL (base64 JPEG)
    name: string,          // 文件名
    w: number, h: number,  // 原始像素尺寸
    tH: number | null,     // 检测到的文字行高 (px)
    lm: 'single' | 'double',
    rawScale: number,      // 原始缩放系数
    normScale: number      // 归一化后的缩放系数 [0.35, 1.0]
  }],
  pages: [{
    L: Array<Cell>, R: Array<Cell>,
    yL: number, yR: number  // 左/右栏剩余高度 (mm)
  }],
  cp: number,              // 当前预览页码
  done: boolean,
  tgtMM: number,           // 目标文字高度 (mm)
  nSplit: number           // 总切割次数
}

interface Cell {
  x: number, y: number, w: number, h: number,  // 位置+尺寸(mm)
  iid: string, src: string | Promise<string>,
  isSp: boolean, si: number, p: number|string, t: number|string
}
