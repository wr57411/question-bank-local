已知函数 f(x) = ax² + bx + c 的图像经过点 (1,2)，且顶点在 x 轴上，求函数表达式。
🖼️

📖 答案

f(x) = 2x² - 4x + 2

解题思路：
1. 由顶点在 x 轴上，得 Δ = b² - 4ac = 0
2. 代入点 (1,2)：a + b + c = 2
3. 顶点 x = -b/(2a)，代入 f(x) = 0 得 -b²/(4a) + c = 0
4. 联立解得 a = 2, b = -4, c = 2
