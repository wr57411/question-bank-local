```markdown
# Git Commit & Push

## Workflow

### Step 1: Check status
git status -sb
git diff --stat
git log --oneline -3

### Step 2: Stage files
git add <specific-files>
Never use git add -A

### Step 3: Commit
git commit -m "type: description"
- feat: new feature
- fix: bug fix
- refactor: code refactoring

### Step 4: Push (SSH)
git remote set-url origin git@github.com:wr57411/question-bank-local.git
git push origin <branch>

### Step 5: Verify
git log --oneline -1

## Key Points
- Remote: git@github.com:wr57411/question-bank-local.git
- Branch: f640/main2
- Always use SSH for push
- Stage specific files only
```
